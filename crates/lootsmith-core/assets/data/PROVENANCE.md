Every file in this folder is a **data table** (names, ids, part lists, numbers)
re-serialised to compact JSON. No art, audio or binaries. A folder the user
picks in **Game data…** always overrides these files.

Sources are public dump repositories generated from the game by the community
tools (`Gibbed.Borderlands2.Datamining`, `BLCM/DataDumper`). None of them states
a license for the data itself; the bundled tables are therefore shipped as
*derived data* with attribution, not as original expression, and users who
prefer to supply their own folder can do so at any time.
